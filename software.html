Conceito de software

Sistemas livres

software livre é qualquer programa de computador que respeita a liberdade dos usuários e o senso de comunidade, permitindo que as pessoas possam executar, estudar, modificar e redistribuir o programa.

Linux

O Linux é o núcleo (kernel) de um sistema operacional de código aberto.

Distribuições

Distribuição é o processo de dividir, organizar e entregar produtos, serviços ou recursos do ponto de origem até o destino final.

Sistemas proprietários

software proprietário (ou privativo) é um programa de computador cujo código-fonte é fechado e pertence exclusivamente ao seu criador, empresa ou organização.

Apple

Apple baseia-se na interseção entre tecnologia disruptiva, design minimalista e usabilidade intuitiva. Mais do que uma fabricante de hardware e software, a Apple Inc.

Microsoft

A Microsoft é uma multinacional americana de tecnologia fundada em 4 de abril de 1975 por Bill Gates e Paul Allen, com sede em Redmond, Washington.

SOFTWARES

O software é um conjunto de instruções lógicas, programas e dados que dizem a um computador, celular ou dispositivo eletrônico o que fazer.

Tipos de licenças

São modelos proprietários, livres/código aberto e formatos comerciais.

Licenciados

é um contrato legal entre o criador do programa e o usuário que define as regras de uso, cópia, distribuição e modificação do sistema.

Livres

refere-se a programas de computador que respeitam a liberdade e a autonomia dos usuários, e não ao seu preço (podendo ser gratuito ou comercializado).

Proprietários

é um programa de computador cujos direitos exclusivos de uso, alteração e redistribuição pertencem ao seu criador ou empresa detentora.

tipos de softwares

é a parte lógica e imaterial do computador (o conjunto de instruções e programas) que comanda o funcionamento do hardware (as peças físicas).

tipos de Sistemas

Um sistema é um conjunto de elementos interdependentes que se conectam para alcançar um objetivo comum.

Aplicativos

é um programa de computador ou de software criado para realizar tarefas específicas e facilitar o dia a dia do usuário em celulares, tablets ou computadores.

tipos de Programação

o divididos principalmente pelo nível de abstração (relação com a máquina) e pelos paradigmas (estilo de raciocínio e organização do código).

Software para diagnóstico

O software de diagnóstico é um programa de computador ou aplicativo utilitário desenvolvido para analisar, identificar, monitorar e solucionar falhas ou gargalos em componentes de hardware, sistemas operacionais e redes de dispositivos eletrônicos (como PCs, smartphones e servidores).

Diagnóstico de software

O diagnóstico de software é o processo técnico que utiliza conceitos, técnicas e ferramentas para identificar, analisar e monitorar falhas, gargalos ou comportamentos indesejados em um sistema ou aplicativo

Diagnóstico de hardware

é o processo de investigação e análise dos componentes físicos de um sistema computacional (como processador, memória RAM, placa-mãe, armazenamento e fontes) para identificar falhas, desgastes ou o mau funcionamento de uma peça.

Ferramentas de Busca e Download

é um sistema de software criado para rastrear, indexar e organizar conteúdos disponíveis na internet, permitindo que os usuários encontrem páginas, imagens, vídeos ou arquivos por meio de palavras-chave.

Plugins

é um pequeno programa ou componente de software instalado em um aplicativo principal para adicionar novas funções ou recursos sem alterar o código original do sistema.

Complementos do navegador

é um pequeno programa de software instalado em um navegador web (como Google Chrome, Mozilla Firefox, Microsoft Edge ou Safari) para adicionar novas funções ou modificar recursos já existentes.

Versão de software

é uma designação (geralmente numérica ou alfanumérica) que identifica um estágio específico de desenvolvimento, atualização ou lançamento de um programa de computador ou aplicativo.

Filtros de busca

ferramenta ou mecanismo de seleção que permite refiná-los, restringindo os resultados apresentados após uma pesquisa inicial.
