Sistemas operacionais ao longo do tempo

Conheça o conceito e os principais lançamentos de Windows, macOS e Linux. As datas indicam o lançamento inicial de cada versão principal; atualizações menores não estão listadas individualmente.

Windows macOS Linux

Microsoft · desde 1985

Windows

Família de sistemas operacionais da Microsoft. As primeiras edições eram ambientes gráficos executados sobre o MS-DOS; a partir do Windows NT, a família passou a usar uma arquitetura própria, que também serve de base às versões atuais.

1985

Windows 1.0

Primeira interface gráfica da família, com janelas lado a lado e programas básicos; dependia do MS-DOS.

1987

Windows 2.x

Permitiu sobrepor janelas e trouxe suporte gráfico melhorado para aplicativos.

1990–1993

Windows 3.x

As versões 3.0, 3.1 e 3.11 popularizaram o ambiente gráfico, os ícones e o uso de programas em grupo.

1993–1996

Windows NT 3.x e NT 4.0

Linha projetada para maior estabilidade e uso profissional, com arquitetura de 32 bits e sistema de arquivos NTFS.

1995

Windows 95

Apresentou o menu Iniciar e a barra de tarefas, elementos que se tornaram marcas da experiência Windows.

1998–2000

Windows 98 e Me

Melhoraram o suporte a USB, internet e multimídia. O Windows Me foi a última edição doméstica baseada no MS-DOS.

2000–2001

Windows 2000 e Windows XP

O 2000 fortaleceu o uso corporativo; o XP unificou as linhas doméstica e profissional sobre a base NT.

2007–2009

Windows Vista e Windows 7

O Vista trouxe a interface Aero e controles de segurança. O Windows 7 refinou o desempenho e a navegação.

2012–2013

Windows 8 e 8.1

Reformularam a interface para telas sensíveis ao toque; a atualização 8.1 recuperou o botão Iniciar.

2015

Windows 10

Retomou o menu Iniciar e adotou atualizações contínuas. A versão 22H2 foi a última atualização de recursos.

2021

Windows 11

Atualizou o visual, reorganizou o menu Iniciar e reforçou requisitos de segurança do computador.

Além dessas versões para computadores pessoais, a Microsoft também criou edições para servidores, celulares e dispositivos embarcados.

Apple · Mac

macOS

Sistema operacional dos computadores Mac. A geração moderna começou como Mac OS X, baseada em tecnologias UNIX da NeXT e no núcleo Darwin. O nome mudou para OS X e depois macOS; em 2025, a Apple passou a numerar as versões pelo ano seguinte ao anúncio.

1984–2001

System 1 a Mac OS 9

Geração clássica dos Macintosh. Evoluiu das primeiras interfaces com janelas e ícones até o Mac OS 9, antes da mudança para a base UNIX.

2001

Mac OS X 10.0 Cheetah

Primeira versão para o público da nova arquitetura, com interface Aqua e base UNIX.

2001–2003

10.1 Puma · 10.2 Jaguar · 10.3 Panther

Melhoraram o desempenho e acrescentaram recursos como busca, mensageiro, troca rápida de usuário e Exposé.

2005–2007

10.4 Tiger e 10.5 Leopard

Tiger apresentou Spotlight e Dashboard. Leopard trouxe Time Machine e ampliou a transição para aplicativos de 64 bits.

2009–2012

10.6 Snow Leopard · 10.7 Lion · 10.8 Mountain Lion

Snow Leopard priorizou eficiência; Lion e Mountain Lion aproximaram alguns recursos do Mac aos do iPhone e iPad.

2013–2015

10.9 Mavericks · 10.10 Yosemite · 10.11 El Capitan

Mavericks iniciou atualizações gratuitas; Yosemite renovou a interface e El Capitan destacou melhorias de desempenho.

2016–2018

10.12 Sierra · 10.13 High Sierra · 10.14 Mojave

Siri chegou ao Mac; High Sierra adotou o sistema de arquivos APFS; Mojave acrescentou o modo escuro.

2019

10.15 Catalina

Separou os aplicativos de mídia e deixou de executar aplicativos de 32 bits.

2020–2022

macOS 11 Big Sur · 12 Monterey · 13 Ventura

Big Sur marcou a mudança visual e a transição para os chips Apple Silicon; Monterey e Ventura ampliaram integração e organização de janelas.

2023–2024

macOS 14 Sonoma e 15 Sequoia

Sonoma ampliou os widgets e os recursos de videoconferência; Sequoia trouxe gerenciamento de janelas e integração com iPhone.

2025–2026

macOS 26 Tahoe e 27 Golden Gate

Tahoe adotou a nova numeração baseada no ano. Golden Gate é a versão seguinte, anunciada em 2026 para computadores com Apple Silicon.

Projeto de código aberto · desde 1991

Linux

Linux é o núcleo (kernel) de um sistema operacional: controla o processador, a memória e os dispositivos. Em geral, as pessoas usam uma distribuição, que combina o núcleo Linux com programas, ferramentas e uma interface gráfica.

1991

Linux 0.01

Primeira publicação do núcleo criado por Linus Torvalds, ainda experimental e voltado a computadores com processadores Intel 386.

1994

Linux 1.0

Primeira versão estável do kernel; marcou a passagem do projeto experimental para um sistema utilizável por mais pessoas.

1996

Linux 2.0

Ampliou o suporte a processadores e à execução de várias tarefas, ajudando o Linux a crescer em servidores e computadores pessoais.

2003

Linux 2.6

Longa série de desenvolvimento que trouxe avanços de desempenho, suporte a hardware e escalabilidade.

2011–2018

Linux 3.x e 4.x

Continuaram a expansão do suporte a dispositivos e arquiteturas. A mudança de número principal não representa, por si só, uma ruptura.

2019–2021

Linux 5.x

Geração com aperfeiçoamentos contínuos no hardware, nos sistemas de arquivos, na segurança e no uso em nuvem.

2022–2025

Linux 6.x

Família de versões que ampliou suporte a processadores e equipamentos recentes. Algumas versões recebem manutenção prolongada (LTS).

2026

Linux 7.x

Nova série do kernel iniciada em 2026. O número da versão é parte da evolução do projeto, não um sistema operacional separado.

Não existe uma lista única com “todas as versões do Linux” como acontece com o Windows: cada distribuição tem seu próprio calendário e numeração. O quadro acima resume as principais séries do kernel.

Exemplos de distribuições Linux

Ubuntu

Distribuição baseada em Debian, conhecida pelas edições para computadores, servidores e nuvem.

Debian

Projeto comunitário conhecido pela estabilidade e por servir de base para outras distribuições.

Fedora

Distribuição comunitária que costuma adotar tecnologias recentes do ecossistema Linux.

Linux Mint

Distribuição para computadores pessoais, com foco em facilidade de uso e opções de ambiente gráfico.
